# TurtleBot3 Maze Navigation

Robotics and Intelligent Systems - IE4060

## Project

Autonomous navigation of TurtleBot3 Burger in a custom
Gazebo maze using ROS 2 Jazzy.

## Objectives

- Create a custom maze environment in Gazebo.
- Map the environment using SLAM.
- Navigate autonomously using Nav2.
- Select destination points using a map.
- Implement and evaluate a Deep Q-learning approach.
- Measure navigation performance.

## Requirements

- Ubuntu with ROS 2 Jazzy
- Gazebo Harmonic
- TurtleBot3 Burger packages
- SLAM and Nav2 packages

## Project Structure

- worlds/: Gazebo world files
- maps/: Saved occupancy maps
- src/: ROS 2 packages
- scripts/: Helper scripts
- results/: Experimental results and screenshots
- report/: Final assignment report
